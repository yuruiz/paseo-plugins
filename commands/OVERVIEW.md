Commands lists the current agent's project, global and live-session commands. The Commands button above the composer opens a popover in the conversation, or a sheet on compact layouts. Search, preview Markdown, enter arguments and send the command to the same agent. Successful sends close the popover. Use Open tab or the Command Center for the full panel with source filters.

It scans shared `.agents/commands` folders plus command or prompt directories for Claude, Codex, OpenCode, Pi and Copilot. Project folders are searched from the working directory up to the Git root; global folders are read on the daemon machine. Other providers contribute the commands their session reports. Files with the same name remain visible with their source paths.

Commands reported by the session run as native slash commands. Other files are sent as prompt templates, with argument substitution. The selected agent provider receives the command and arguments, or the expanded Markdown prompt, under that agent's normal data-handling rules. Native commands may cause the provider to run tools. Template mode does not execute provider frontmatter settings, shell substitutions or file directives. Commands belonging to installed Claude plugins appear through the session without a file preview. The plugin does not edit command files or execute shell commands itself.

Requires Paseo 0.13.0 or newer on the daemon and client. Plugins must be enabled on the host. Git installation needs Node.js 22 or newer and npm to install the locked YAML parser dependency. Commands are sent only when the selected agent is not busy; sending errors remain visible with the arguments preserved. The button is available for existing agents; an empty draft gets it after the first message creates the agent.
