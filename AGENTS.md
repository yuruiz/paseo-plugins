# Git workflow

- When the user says `push` or `commit / push`, integrate the requested changes into `main` and push `main`.
- Do not push independent branches to the remote unless the user explicitly requests it.
- Local branches and worktrees may be used to prepare and verify changes before integrating into `main`.
