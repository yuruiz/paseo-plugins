# 设置面板设计

本轮按用户要求，使用 design-harness-interaction 与 design-harness-visual 的交互、视觉方法整理现有设置。设计直接落实到插件；范围为设置抽屉及控件，不建立独立设计工作台。

## 基线与组织

基线是本地正式 React Native Web 面板，真实 Git RPC、开发环境设置存储；原界面宽 320px，全部设置在同一滚动页，字体与字号使用大量按钮。截图基线：`artifacts/scm-refinement-settings.png`。

整理为宽 380px、最大不超过视口的设置抽屉。固定标题、分类 Tab、保存状态、插件版本号和恢复默认；仅内容区滚动。分类按用户正在完成的任务组织：

| 分类 | 设置                                                                       |
| ---- | -------------------------------------------------------------------------- |
| 外观 | 显示侧栏、列表/目录树、滚动条                                              |
| 代码 | 字体、自定义字体、字号、字重、实时字体预览、语法着色、行号、换行、Tab 宽度 |
| 比较 | 全部/暂存/未暂存、差异布局、上下文、忽略空白                               |
| 行为 | 标签缓存数量、 默认预览、自动刷新、刷新间隔                                |

两个或三个需要对比的简短选项保留分段选择；字体、字号、字重、Tab 宽度、上下文和刷新间隔使用下拉。字号与字重并排，缩短代码页。关闭自动刷新时禁用间隔选择，保留原来的间隔值。

## 交互与反馈

分类使用 tablist/tab/tabpanel 语义，支持左右键、Home/End、单一 Tab 焦点入口。切换分类不改变配置值，回到某分类时内容从顶部开始。

Web 使用原生 select，支持键盘、读屏和系统菜单定位；原生客户端使用选择浮层。继续复用现有 host settings 保存队列、冲突合并和失败重试。保存失败始终在底部可见，不随分类内容滚走；恢复默认作用于全部分类。

复用 Paseo 色彩、系统 UI 字体、Codicons 和现有开关。选中分类使用底部强调线；输入框与下拉统一 32px、3px 圆角，保留清晰的键盘焦点。

## 验证边界

从真实设置入口验证分类切换、下拉选择、自定义字体、联动禁用、重载持久化、保存错误与重试、窄屏滚动、深浅主题和焦点。浏览器设置存储为本地开发代理；安装后另做真实插件检查。桌面/Web 为实际交互证据，iOS/Android 原生选择浮层仅完成类型检查。

方法来源：用户指定的 design-harness 项目中的 `skills/design-harness-interaction/SKILL.md`、`skills/design-harness-visual/SKILL.md`，以及共同的交付保真、交互方法、视觉方法与评价规则。用户仍可继续评审视觉与分组，这里的验证结果不代替用户验收。

## 交付检查

四分类导航、下拉、自定义字体、实时预览、联动禁用、跨分类保存错误、重试、重载恢复和全局恢复默认均已在浏览器验证。深浅主题与 360px 窄屏已实际检查截图，较矮窗口下分类与页脚固定。切换分类不触发设置写入；保留既有偏好和存储 schema。检查证据与运行边界见 [验证记录](verification.md#设置分类验收)。

标签缓存数量使用 1–10 个的下拉选择，默认 5 个。缓存命中保留页面及滚动位置；当前标签始终保留，内容较大时按估算预算淘汰旧页。差异布局只保留「左右 / 统一」，历史补丁值在读取时迁移为统一，不重置其他偏好。
