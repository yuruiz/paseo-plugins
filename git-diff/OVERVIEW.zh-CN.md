在 Paseo 中审阅未提交改动和连续 commit 区间，查看分支关系，并将行评论及代码上下文作为原生 Review 反馈发送给对话。

打开后，中间的 Git Diff 只展示差异；右侧 Git Review 面板上方是提交图，下方是文件列表。两者共享范围、文件选择、预览标签和已阅标记。默认定位当前分支，自动审阅分叉点之后的全部提交和未提交改动。Graph 可收起，并可拖动分隔线调整高度。点击文件默认复用预览标签，固定或双击标签后保留该页。

切换到“所有分支”可查看分叉与合并关系；点击提交或 Working Changes 联动文件和 diff。可用 Shift 点击、键盘扩选、拖选或上下两个紫色滑块调整范围；拖到边缘时自动滚动。包含 Working Changes 时，同时审阅未提交改动。

“当前分支”显示第一父链，并标记相对于可选基准分支的分叉点。基准默认主分支；分叉点及更早的共享历史不可选。没有独有提交时只能选择 Working Changes；当前就是基准分支时不推断分叉点。

点击 diff 行号旁的加号添加或编辑评论，可评论原始侧和修改侧。评论保存目标行及附近代码快照，按工作区和比较范围隔离，通过 Paseo 持久化。点击“发送反馈”选择本工作区的对话，使用 Paseo 原生 Review 附件发送评论和上下文；发送成功后清理已发送评论，失败时保留草稿。

支持文件筛选、增删行统计、统一或左右 diff、忽略空白、换行、差异块导航、文件预览和已初始化子模块。折叠代码可向上或向下每次展开 20 行，也可全部展开。Ctrl/Cmd+F 搜索文件两侧内容，包括折叠上下文；Enter / Shift+Enter 跳转，Escape 关闭。

要求 Paseo daemon 和客户端 >=0.12.0，主机可运行 Git。Git 读取在所选 daemon 本地执行，不自动 fetch、checkout 或修改暂存区和工作树。仅在用户点击发送反馈时向所选对话发送代码上下文。区间最多 10000 个提交且须沿同一第一父链；单文件上限 1 MiB，补丁上限 2 MiB，二进制仅显示状态。子模块内部历史需选择对应已初始化仓库。
